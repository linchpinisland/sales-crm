# sales-weekly-picks — 이번 주 챙길 고객 뽑기

## 입력 파일 규약

작업 폴더(또는 사용자가 지정한 폴더)에서 다음 중 하나를 찾는다.

| 형태 | 파일 | 비고 |
|---|---|---|
| CSV 3개 | `고객.csv`, `상담기록.csv`, `구매기록.csv` | 시트 메뉴 [고객관리] → [CSV 내보내기]가 만드는 파일. UTF-8(BOM 포함) |
| xlsx 1개 | 아무 이름의 `.xlsx` | 구글 시트 파일 → 다운로드 → Excel. 탭 이름 `고객` `상담기록` `구매기록` |

헤더는 시트 헤더와 같다(아래 표). 없는 컬럼은 빈 값으로 취급하고, **없다고 실패하지 않는다.**

- 고객: `고객ID 고객명 담당자 연락처 업종 단계 단계변경일 구매의향 마지막연락일 생일 기념일 고민포인트 취향/선호 다음제안아이디어 메모 등록일`
- 상담기록: `기록ID 상담일 고객ID 고객명 유형 내용 결과 다음액션 다음액션일 등록일시`
- 구매기록: `구매ID 구매일 고객ID 고객명 제품/서비스 특징/사양 금액 재구매주기(일) 다음구매예정일 계약만료일/납기일 수금예정일 수금상태 구매당시의향 고민포인트 다음제안 메모`

파일을 찾지 못하면 어디서 내보내는지 한 줄로 안내하고 멈춘다. 파일을 추측해서 만들지 않는다.

## 절차

1. **로드·검증** — 세 파일을 읽고 행 수, 고객ID 누락, 날짜 파싱 실패 수를 센다. 문제는 마지막 "데이터 품질 메모"에 적는다.
2. **오늘 날짜** — 사용자가 주지 않으면 실행일. 결과 상단에 기준일을 적는다.
3. **지표 계산** (고객별, 계산으로만):
   - 미접촉 일수 = 오늘 − max(마지막연락일, 상담일들, 구매일들)
   - 견적 대기 = 상담기록 중 유형=견적발송 · 결과=대기 인 건의 경과 일수
   - 재구매 도래 = 다음구매예정일(비어 있으면 구매일+재구매주기) − 오늘
   - 만료 임박 = 계약만료일/납기일 − 오늘
   - 미수금 = 수금상태≠완료 인 구매의 금액 합, 수금예정일 경과 일수
   - 기념일 = 생일·기념일의 다음 도래일 − 오늘
   - 누적 매출, 최근 6개월 매출, 구매의향
4. **정성 결합** — 고객의 `고민포인트` `취향/선호` `다음제안아이디어`, 최근 상담 `내용`·`다음액션`, 구매의 `특징/사양`·`고민포인트`·`다음제안`을 한 줄로 요약한다. 원문 표현을 살리고 지어내지 않는다.
5. **우선순위** — 영업이 돈으로 느끼는 통증 순서. 같은 등급이면 금액·경과 일수가 큰 순.
   1. 미수금 기일 경과
   2. 견적 후 무응답 (7일 이상)
   3. 재구매 주기 도래 (7일 이내) / 계약·납기 만료 임박 (7일 이내)
   4. 구매의향 "상"인데 7일 이상 미접촉
   5. 장기 미접촉 (21일 이상, 단계≠이탈)
   6. 생일·기념일 (3일 이내)
6. **산출** — 아래 형식으로 `이번주_챙길고객.md`를 작업 폴더에 쓴다. 파일명은 사용자가 바꾸라 하면 따른다.

## 출력 형식

```markdown
# 이번 주 챙길 고객 (기준일 YYYY-MM-DD)

## 지금 연락할 5곳

| # | 고객 | 왜 지금인가 | 첫 마디 제안 |
|---|---|---|---|
| 1 | 세광기계 | 미수금 890만원, 기일 18일 경과. 결재 절차 느린 곳 | "문태호 이사님, 지난번 말씀하신 결재 진행 어디까지 갔는지 여쭤봐도 될까요" |
| … | | | |

## 고객별 다음 제안 (전체)

| 고객 | 단계 | 의향 | 마지막 연락 | 신호 | 다음 제안 |
|---|---|---|---|---|---|

## 데이터 품질 메모
- 고민포인트가 비어 있는 고객 N곳: …
- 날짜 파싱 실패 N건: …
```

"왜 지금인가"는 **계산된 숫자 + 정성 한 줄**. "첫 마디 제안"은 담당자 호칭·취향(전화/카톡/방문 선호)을 반영한 실제로 말할 문장 1개.

## 가드

- 숫자(일수·금액·건수)는 반드시 계산 결과. 암산·추정 금지.
- 데이터에 없는 사실을 지어내지 않는다. 판단이 들어가면 문장 끝에 `(추정)`.
- 사용자가 "거래처명 빼고" 또는 "코드명으로"라 하면 고객명을 `고객ID`로 치환해 출력한다(회사 밖 반출용).
- 5곳이 안 나오면 억지로 채우지 않고 나온 만큼만.
- 전화번호·연락처는 출력하지 않는다(필요 시 시트에서 본다).

## 보조 스크립트 (선택)

`scripts/summarize.py` 가 있으면 지표 표를 먼저 뽑아 근거로 쓴다. 없으면 직접 계산한다(수백 행 규모라 충분).

```bash
python scripts/summarize.py --dir . --today 2026-09-16
```
