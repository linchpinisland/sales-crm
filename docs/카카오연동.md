# 카카오톡 "나에게 보내기" 연동

내 카카오 계정으로 **나 자신에게만** 메시지를 보내는 방식입니다. 사업자 인증·채널·비용이 필요 없습니다. 메시지는 카카오톡 "나와의 채팅"에 도착합니다.

## 1. 카카오 개발자 앱 만들기 (한 번만)

1. https://developers.kakao.com 접속 → 카카오 계정으로 로그인.
2. **내 애플리케이션 → 애플리케이션 추가하기**. 앱 이름 "고객관리", 회사명은 본인 이름도 됨 → 저장.
3. 만든 앱 클릭 → **앱 키** 에서 **REST API 키** 복사.
4. 왼쪽 메뉴 **카카오 로그인** → 활성화 설정 **ON**.
5. 같은 화면 **Redirect URI → 등록** 에 시트 설정 탭의 **웹앱 URL**(…/exec)을 그대로 붙여넣기 → 저장.
6. 왼쪽 메뉴 **동의항목** → "카카오톡 메시지 전송" 을 **이용 중 동의** (또는 선택 동의)로 설정 → 저장.
   - 이 항목이 안 보이면 "카카오 로그인 활성화"가 먼저 되어야 합니다.

## 2. 시트에 키 넣고 연결

1. 시트 **설정** 탭 → "카카오 REST API 키" 값에 3번의 키 붙여넣기. (Client Secret 은 콘솔에서 "사용함"으로 켠 경우에만)
2. 웹앱 열기 → **설정** → **[카카오 연결]**.
3. 새 탭에 카카오 동의 화면 → **동의하고 계속하기**.
4. "카카오톡 연결 완료" 페이지가 뜨고, 카카오톡 "나와의 채팅"에 테스트 메시지가 옵니다.
5. 웹앱 설정 화면의 상태가 **연결됨** 으로 바뀝니다. [테스트 발송] 으로 재확인.

## 3. 작동 원리와 유지

- 액세스 토큰(약 6시간)과 리프레시 토큰(약 2개월)을 스크립트 속성에 저장합니다. 시트에는 저장하지 않습니다.
- 매일 아침 발송 직전에 액세스 토큰을 자동 갱신하고, 리프레시 토큰은 카카오가 새 것을 주면 교체합니다. 별도로 주 1회 갱신 트리거가 돕니다.
- 갱신 실패(예: 카카오 앱을 지웠거나 동의를 철회한 경우) → 대시보드에 "연결 끊김" 배너 + 이메일 안내. 다시 **[카카오 연결]** 하면 됩니다.
- 요약이 200자를 넘으면 (1/3) 처럼 나눠서 여러 건으로 옵니다.

## 4. 문제 해결

| 증상 | 원인 · 조치 |
|---|---|
| 동의 후 "KOE006" 또는 "redirect_uri mismatch" | 콘솔 Redirect URI 와 설정 탭 웹앱 URL 이 한 글자라도 다름. 웹앱 URL 을 새로 배포했다면 콘솔도 갱신 |
| "KOE101 / invalid client" | REST API 키 오타. Client Secret 을 켰는데 설정에 안 넣은 경우 |
| 연결은 됐는데 메시지 안 옴 | 동의항목에서 "카카오톡 메시지 전송"이 설정 안 됨 → 설정 후 [연결 해제] → [카카오 연결] 다시 |
| 메시지의 "웹앱 열기" 버튼이 없음 | 링크 도메인 미등록 시 텍스트만 보내도록 자동 재시도합니다. 버튼을 원하면 콘솔 **플랫폼 → Web → 사이트 도메인** 에 `https://script.google.com` 등록 (실측 필요) |
| Redirect URI 에 script.google.com 이 등록되지 않음 | 카카오 정책 변동 가능성. 등록이 거부되면 이메일 폴백을 쓰거나 Cloudflare Worker 같은 중계 URL 필요 (범위 밖) |

## 5. 알림톡과의 차이

| | 나에게 보내기 (이 도구) | 알림톡 |
|---|---|---|
| 받는 사람 | 나만 | 고객·동료 누구나 |
| 필요한 것 | 카카오 계정 + 개발자 앱 | 카카오톡 채널 + 사업자 인증 + 템플릿 심사 |
| 비용 | 무료 | 건당 과금 |
| 용도 | 개인 알림·리마인더 | 고객 대상 공식 메시지 |
