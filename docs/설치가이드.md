# 설치 가이드 (비개발자용, 15분)

준비물: 구글 계정, 크롬 브라우저. (카카오톡 알림은 선택) 코드는 한 줄도 안 칩니다.

## 1단계. 시트 사본 만들기 (1분)

1. 이 링크를 누릅니다 → **[템플릿 사본 만들기](https://docs.google.com/spreadsheets/d/1W9yToroXKZdTYdUYhm09E1MYHAN3OhAxxl_EGJKSESs/copy)**
2. "문서를 복사하시겠습니까?" 화면에서 **사본 만들기**. 이름은 "고객관리"처럼 바꾸셔도 됩니다.
3. 새로 열린 시트 상단 메뉴에 **[고객관리]** 가 보이면 정상. (안 보이면 새로고침 후 5초 대기)

> 링크가 열리지 않으면 "붙여넣기 설치"(맨 아래)를 따르세요.

## 2단계. 초기 설정 실행 (2분)

1. 메뉴 **[고객관리] → [① 초기 설정 실행]**.
2. "승인 필요" 창 → 계속 → 내 계정 선택 → "확인되지 않은 앱" 경고가 나오면 **고급 → (프로젝트명)(안전하지 않음)으로 이동** → 허용.
   - 이 경고는 내가 만든 스크립트를 내가 쓰는 것이라 뜨는 표준 안내입니다.
3. 다시 **[① 초기 설정 실행]** 을 한 번 더 누르면 "초기 설정 완료" 창이 뜹니다.
   - 탭 7개(고객·상담기록·구매기록·알림규칙·알림로그·설정·_메타), 드롭다운, 기본 규칙 9개, 트리거 3개가 만들어집니다.

## 3단계. 웹앱 배포 (3분)

1. **확장 프로그램 → Apps Script**.
2. 오른쪽 위 **배포 → 새 배포**.
3. 톱니(유형 선택) → **웹 앱**.
4. 설명: 아무거나 / 실행 사용자: **나** / 액세스 권한: **본인만** → **배포**.
5. 뜨는 **웹 앱 URL**(…/exec 로 끝남) 복사.
6. 시트의 **설정** 탭 → "웹앱 URL" 값 칸에 붙여넣기.
7. 메뉴 **[고객관리] → [웹앱 열기]** 로 열어보기. 휴대폰에서는 URL을 크롬으로 열고 "홈 화면에 추가"하면 앱처럼 씁니다.

> 코드를 수정한 뒤에는 **배포 → 배포 관리 → 연필 → 버전: 새 버전 → 배포**. "새 배포"를 만들면 URL이 바뀌어 카카오 설정도 다시 해야 합니다.

## 4단계. (선택) 카카오톡 연결 (5분)

**건너뛰어도 됩니다.** 3단계까지만 하면 매일 아침 요약이 내 Gmail 로 옵니다. 영상도 이메일 기준입니다.

`docs/카카오연동.md` 를 따르세요. 요약: developers.kakao.com 에서 앱 하나 만들고 REST API 키를 설정 탭에 넣은 뒤, 웹앱 **설정 → 카카오 연결**.

카카오를 건너뛰어도 됩니다. 그러면 매일 아침 요약이 내 Gmail 로 옵니다(설정 "이메일 폴백" Y).

## 5단계. 써보기 (3분)

1. 메뉴 **[고객관리] → [데모 데이터 넣기]** 로 가상 거래처 25곳을 넣어 화면을 확인.
2. **[오늘 알림 미리보기]** 로 어떤 알림이 걸리는지 보기 → **[오늘 알림 지금 보내기]** 로 카톡/메일 수신 확인.
3. 실제 사용 전 **[데모 데이터 지우기]**.
4. 고객은 시트 **고객** 탭에 직접 입력하거나(고객ID는 자동), 웹앱 **기록 입력**에서 추가.
5. 상담·구매를 기록하면 마지막연락일이 자동 갱신되고, 매일 아침(설정 시각) 요약이 옵니다.

## 자주 묻는 것

| 증상 | 조치 |
|---|---|
| 메뉴 [고객관리]가 안 보임 | 새로고침. 그래도 없으면 확장 프로그램 → Apps Script 에서 `onOpen` 실행 |
| "탭이 없습니다" 오류 | [① 초기 설정 실행] |
| 아침 요약이 안 옴 | 시트 메뉴 [상태 점검] 에서 트리거 확인 → 없으면 [트리거 다시 설치]. 시간 트리거는 ±15분 오차 |
| 카카오 "연결 끊김" 배너 | 웹앱 설정 → 카카오 연결 다시. 리프레시 토큰은 약 2개월이며 매일 발송이 자동 갱신함 |
| 웹앱이 옛 버전 | Apps Script → 배포 → 배포 관리 → 새 버전 |
| 시트를 동료와 공유해도 되나 | 설정 탭에 카카오 키가 있으니 **공유하지 마세요**. 팀용은 이 도구 범위 밖 |

## 붙여넣기 설치 (템플릿 링크 없이)

1. 새 구글 시트 생성 → 확장 프로그램 → Apps Script.
2. 리포의 `src/` 폴더 파일들을 같은 이름으로 만들어 내용 붙여넣기. `.gs` 는 "스크립트", `.html` 은 "HTML" 파일로. `appsscript.json` 은 프로젝트 설정 → "매니페스트 파일 표시" 후 교체.
3. 저장 후 시트로 돌아가 새로고침 → 2단계부터 진행.

개발자는 `clasp` 사용: `npm i -g @google/clasp` → `clasp login` → `.clasp.json.example` 을 `.clasp.json` 으로 복사해 scriptId 입력 → `clasp push`.
